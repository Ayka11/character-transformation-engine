## Runtime decision trace

Every adaptive decision should be reconstructable from:

`state inputs + algorithm version + rule IDs + input hash → output + explanation + output hash`

## Compatibility

The engine keeps three vectors separate:

- V1 Bio/Tempo
- V2 Values Alignment
- V3 Behavioral Synergy

Data completeness, recency and consistency are reported separately.
