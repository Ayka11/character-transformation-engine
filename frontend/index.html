STEP 1 · UNDERSTAND THE MEASURES

Master Matrix

The catalogue behind the model. P1 is current state and resources; P2 stable traits; P3 self-regulation and cognition; P4 values; P5 observable behavior. Missing values stay missing—never assume a perfect score.

STEP 2 · OBSERVE TODAY

Character Model

Rate how you are doing today from 0–10. This creates a state/capacity snapshot; it does not estimate your entire personality. Use real observations rather than trying to get a “good” result.

Your assessment and practice plan will appear here. You can adjust the values at any time.

Enter two profiles using Master Matrix item IDs and values on the same 0–10 scale. The tool reports observed differences and registered conditional heuristics. It does not calculate a single compatibility percentage or decide whether people should be together or work together.
